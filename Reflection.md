# One-Page Reflection

## CIP-A103 Network Defence Traffic Analysis Reflection
During the completion of the CIP-A103 Week 01 labs, I developed practical skills in network topology design, binary-to-decimal number conversion, and IP subnetting for both Class B and Class C networks. 

### Operational Lesson 1: Binary Is the Foundation of Subnetting
One of the most valuable lessons learned was that subnetting cannot be understood without a solid grasp of binary. 

### Operational Lesson 2: Matching Subnet Size to Actual Need
Another important lesson was the value of right-sizing subnets to actual host requirements rather than defaulting to standard block sizes.

### Operational Lesson 3: Documentation Supports Deployment
The network diagram and network ID exercises highlighted how clear documentation results in successful deployment. Mapping out devices and recording subnet masks, host bits, and address ranges in structured tables showed that a well-documented plan prevents addressing conflicts and makes a network easier to troubleshoot and expand later.

### Security Risk Discovered
A key security risk identified during these labs was the potential for address space misconfiguration and overlap. Without careful subnet planning, ip ranges can overlap or unassigned subnets can be inadvertently exposed, creating routing conflicts or unintended access paths between network segments.

### Conclusion
Completing these labs strengthened my understanding of IP addressing, binary number systems, and network topology design. I learned how to calculate subnet masks and host ranges accurately, design multi-subnet addressing schemes for larger networks, and document a network's structure before deployment.
